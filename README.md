# MID DEV — Landing Page

Landing page satu halaman untuk **MID DEV**, agency jasa pembuatan website & software dengan model kontrak **beli putus** (sekali bayar, tanpa biaya bulanan wajib).

Halaman ini adalah satu file HTML mandiri — tanpa build step, tanpa dependency yang perlu di-install, dan **tanpa file aset terpisah**: logo (WebP), 4 cuplikan video portofolio interaktif 14 detik (WebM + poster WebP), **5 potret tim dari PDF**, dan **kartu QRIS pembayaran** disematkan sebagai data URI di dalam `index.html`.

## Menjalankan secara lokal

Cukup buka `index.html` di browser, atau jalankan server statis:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Lalu buka <http://127.0.0.1:8000/index.html>.

Untuk menguji proxy AI secara lokal (opsional) — butuh API key aktif — jalankan:

```bash
node proxy-dev-server.js
```

Lalu buka <http://127.0.0.1:8000/index.html>. Server ini menyajikan file statis sekaligus menangani `POST /api/gemini` dengan API key yang diatur secara lokal.

## Struktur

```
.
+-- index.html         # seluruh halaman: markup, CSS, JS, logo + 4 video/poster 14 detik + 5 potret tim + QRIS (data URI)
+-- api/
|   +-- gemini.js      # Vercel serverless function: proxy Gemini (API key di env var, bukan di client)
+-- README.md
```

Widget Konsultan AI (disematkan di `index.html` sebagai `<style id="middevAiFx">` + `<script id="middevAiScript">`) punya 3 state utama: **kosong** (hanya sapaan) → **berdiskusi** (chat + chip modul) → **terkonfirmasi** (klien sudah yakin → tombol WhatsApp tampil). Sumber kebenarannya ada di `ai-widget.js`; `patch-v41.js` menyuntik ulang file itu ke `index.html` (idempoten).

Tidak ada `assets/`, tidak ada file gambar/video yang perlu di-deploy. `capture-clips*.js`, `capture-clip3.js`, `encode-clips.js`, `fix-clip1.js`, `probe-interactions.js`, `probe-kopi.js`, `patch-showcase.js`, `patch-v32.js`, `patch-v33.js`, `patch-v34.js`, `ai-widget.js`, `proxy-dev-server.js`, `v38-test.js`, `v39-test.js`, `v32-test.js`, `v33-test.js`, `v34-test.js`, `v35-test.js`, `v34-navprobe.js`, `v33-shots.js`, `make-logo*.js`, `mid-dev-logo*.webp`, `pre-*.html`, `fix-v39-test*.py`, `upd-readme-v*.py`, `fix-v38-test-proxy.py`, `patch-v41.js`, `v41-test.js`, `v41-mock-test.js`, `qa-v41-shots.js`, `probe-tokens*.js`, `probe-unesc.js`, `wait-quota.js`, folder `portfolio-clips/` dan `pdf-read/` di direktori kerja hanya bahan baku/patch helper; semuanya tidak termasuk repo (lihat `.gitignore`).
